# L0005 — lista świateł klastrów przepełniona

**Co się stało:** Przypisanie świateł do klastrów zapisało więcej wpisów, niż mieści `max_light_indices`. Klastry, które się nie zmieściły, dostały krótszą (albo pustą) listę, więc część świateł nie oświetla pikseli w tych klastrach.

**Jak naprawić:** Zwiększ `ClusterSettings::max_light_indices`, zmniejsz zasięgi świateł (`Light::with_range`) albo zmniejsz liczbę klastrów (większy `tile_size`, mniej `slices`). Zasięg wyprowadzony z natężenia (`AUTO_RANGE_CUTOFF_LUX`) bywa duży dla mocnych świateł.
