# R0107 — bind group nie pasuje do layoutu

**Co się stało:** Bind group albo jego layout łamie reguły bindingów. Przy tworzeniu bind groupy: brakuje bindingu z layoutu, zasób ma inny rodzaj niż binding, zasób tablicowy trafił do wpisu bez `count` (lub odwrotnie), tablica ma zero elementów, więcej elementów niż `count` albo — bez `Features::PARTIALLY_BOUND_BINDING_ARRAY` — inną liczbę niż `count`. Przy tworzeniu layoutu (ADR-0017): `count` bez `Features::TEXTURE_BINDING_ARRAY`, suma elementów tablic widocznych dla jednego etapu powyżej `Limits::max_binding_array_elements_per_shader_stage` (tablice samplerów liczą się też do `max_binding_array_sampler_elements_per_shader_stage`), uniform buffer w grupie z tablicą albo tablica buforów lub tekstur storage (nieobsługiwane).

**Jak naprawić:** Uzupełnij wpisy bind groupy zgodnie z layoutem i dopasuj długość tablicy do `count`. Uniform buffer przenieś do osobnej grupy, bufory i tekstury storage wiąż pojedynczo, a liczbę elementów tablic zmniejsz do limitów adaptera albo sprawdź `Caps` przed użyciem tablic (profil Web ich nie ma).
