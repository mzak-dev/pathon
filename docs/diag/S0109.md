# S0109 — niepoprawny zasób albo binding w shaderze

**Co się stało:** Deklaracja zasobu (`var<uniform>`, `var<storage>`, tekstura, sampler) nie przechodzi walidacji naga: brak `@group(g) @binding(b)`, niedozwolony typ albo przestrzeń adresowa, albo dwa zasoby używane przez jeden entry point mają ten sam `@group` i `@binding`. Błąd wskazuje deklarację w oryginalnym pliku; przy kolizji tę, która powtarza już zajęty slot.

**Jak naprawić:** Dopisz brakujące atrybuty albo nadaj każdemu zasobowi grupy bindów własny numer `@binding`. Layout z refleksji (`reflect_bind_groups`) i layout potoku muszą zgadzać się z tymi numerami.
