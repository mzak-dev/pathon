# Q0002 — transfer wyjściowy nie jest jeszcze zaimplementowany

**Co się stało:** `TonemapSettings::output` ma wariant inny niż `OutputTransfer::Srgb` (`Pq`, `ScRgb`). Tonemapping do HDR dochodzi z M4-16 razem z `SurfaceColorSpace`, więc paczka zgłasza ostrzeżenie raz i używa ścieżki SDR (sRGB). Obraz jest poprawny, tylko w SDR.

**Jak naprawić:** Użyj `OutputTransfer::Srgb`. Wyjście HDR włączy się po M4-16, gdy `get_capabilities` pokaże obsługiwaną przestrzeń kolorów powierzchni.
