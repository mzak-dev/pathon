# G0007 — ta sama historia zadeklarowana z różnymi opisami

**Co się stało:** `history_texture` wywołano dwa razy z tą samą nazwą w jednym widoku i klatce, ale z innym formatem, rozmiarem lub liczbą mipów. Nazwa wskazuje jedną parę tekstur w `HistoryStore`, więc dwa różne opisy nie mogą jej współdzielić.

**Jak naprawić:** Zadeklaruj historię raz i przekaż uchwyty dalej albo nadaj drugiej inną nazwę. Powtórzone wywołanie z identycznym opisem jest dozwolone i zwraca tę samą parę.
