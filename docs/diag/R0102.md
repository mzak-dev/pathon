# R0102 — subresource odczytany, zanim cokolwiek go zapisało

**Co się stało:** Pass czyta treść (próbkowanie, `LoadOp::Load`, kopia źródłowa), której nic wcześniej nie zapisało — np. mip Hi-Z przed downsamplingiem.

**Jak naprawić:** Ustal kolejność passów tak, by producent był przed konsumentem, albo użyj `LoadOp::Clear`.
