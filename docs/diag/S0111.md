# S0111 — błąd składania shadera

**Co się stało:** Składanie wesl nie powiodło się z przyczyny bez własnego kodu: ta sama nazwa zadeklarowana dwa razy w jednym module (lokalizacja wskazuje drugą deklarację), ta sama nazwa zaimportowana dwa razy, import o niedostępnej widoczności albo błąd ścieżki. Komunikat wesl jest pokazany bez kolorów ANSI.

**Jak naprawić:** Zmień nazwę jednej z deklaracji albo zaimportuj ją pod inną (`import a::b as c;`).
