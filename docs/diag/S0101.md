# S0101 — błąd składni shadera

**Co się stało:** Parser wesl albo naga nie rozumie źródła shadera: brakujący nawias, średnik, nieoczekiwany token. Komunikat pokazuje plik, linię i kolumnę w **oryginalnym** pliku (moduł albo shader główny), nie w złożonym tekście ([ADR-0032](../adr/0032-bledy-shaderow-z-lokalizacja.md)). Podpowiedź wylicza, co parser przyjąłby w tym miejscu; gdy lista jest długa, jest to tylko wskazówka, że wyrażenie albo instrukcja jest niedokończona. Błąd w innej linii niż pokazana zdarza się, gdy brakujący `)` lub `}` kończy poprzednią instrukcję dopiero tutaj.

**Jak naprawić:** Popraw wskazane miejsce, a gdy wygląda poprawnie, sprawdź linię wyżej. W buildzie w tle (`BackgroundCompiler`) permutacja zostaje w stanie `Failed`, dopóki nie zarejestrujesz poprawionego źródła (`add_root` / `add_module`).

```wgsl
return vec4<f32>(scaled, 0.0, 1.0;   // brak `)`
```
