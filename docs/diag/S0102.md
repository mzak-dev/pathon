# S0102 — import modułu, którego nie zarejestrowano

**Co się stało:** Shader ma `import package::nazwa::element;`, ale żaden moduł nie jest zarejestrowany pod ścieżką `nazwa` (`ShaderComposer::add_module`, `ShaderLibrary::add_module`, `BackgroundCompiler::add_module`). Błąd wskazuje linię `import` w pliku, który go zawiera. Podpowiedź: najbliższa zarejestrowana ścieżka (literówka), a gdy żadna nie przypomina wpisanej, lista zarejestrowanych modułów.

**Jak naprawić:** Popraw ścieżkę w `import` albo zarejestruj moduł przed składaniem shadera. Ścieżka rejestracji `lighting::pbr` odpowiada `package::lighting::pbr`.
