# T0001 — czasy GPU passów niedostępne

**Co się stało:** `pathon-profile` nie może mierzyć passów na GPU: urządzenie nie ma `Features::TIMESTAMP_QUERY`, nie udało się utworzyć zbiorów zapytań albo cel to web (brak blokującego odczytu bufora). Spany CPU działają dalej.

**Jak naprawić:** Poproś o funkcję w `DeviceRequest::optional_features` (`Features::TIMESTAMP_QUERY`), zanim zbudujesz renderer; przy urządzeniu hosta włącz ją na jego urządzeniu. Na webie zostają spany CPU.
