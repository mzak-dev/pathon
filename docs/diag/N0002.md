# N0002 — niepoprawna kamera

**Co się stało:** Opis kamery (`CameraDesc` albo `Projection`) łamie ograniczenia: pionowe FOV poza przedziałem `(0, π)`, płaszczyzna bliska niedodatnia albo `NaN`, płaszczyzna daleka niedalsza niż bliska, wysokość projekcji ortograficznej niedodatnia. Komunikat podaje, które.

**Jak naprawić:** Użyj `0 < near < far` (dla perspektywy `far` może być `None`: nieskończona) i `0 < vertical_fov < π`. Konwencje: układ prawoskrętny, Y w górę, kamera patrzy wzdłuż -Z, głębia reverse-Z ([sloty](../slots.md)).
