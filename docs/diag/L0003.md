# L0003 — instancja pominięta: nieznany mesh albo materiał

**Co się stało:** Instancja w migawce sceny wskazuje mesh, którego nie ma w `GeometryPool` (usunięty albo z innej puli), albo materiał spoza `MaterialTable`. Instancja nie jest rysowana; ostrzeżenie pojawia się raz na zmianę liczby takich instancji.

**Jak naprawić:** Po usunięciu mesha albo materiału zaktualizuj instancje, które go używały. `MaterialHandle::DEFAULT` oznacza materiał o indeksie 0 tablicy materiałów: dodaj go jako pierwszy.
