# W0002 — niepoprawne dane morph targets

**Co się stało:** `MorphTargets::upload` odrzucił dane: zero wierzchołków, zero celów, strumień delt, który nie jest pusty i nie ma dokładnie jednej delty na wierzchołek, delta nie jest skończona, albo dane nie mieszczą się w limicie bufora storage urządzenia.

**Jak naprawić:** Podaj dla każdego celu `positions`, `normals` i `tangents` puste (zerowe delty) albo długości `vertex_count`, z samymi skończonymi wartościami. Bardzo duże zestawy podziel na kilka `MorphTargets`.
