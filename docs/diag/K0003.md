# K0003 — plik shadera nie jest czytelnym tekstem UTF-8

**Co się stało:** `pathon-hot` nie mógł odczytać pliku (mimo kilku prób, edytor mógł go trzymać) albo jego bajty nie są poprawnym UTF-8. Plik jest pominięty, poprzednia wersja zostaje w użyciu. To **ostrzeżenie**.

**Jak naprawić:** Zapisz plik jako UTF-8 (bez znaków sterujących i binarnych śmieci); komunikat zawiera błąd systemu przy problemie z odczytem.
