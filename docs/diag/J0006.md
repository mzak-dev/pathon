# J0006 — błąd shadera lub potoku GI

**Co się stało:** Shadery WESL GI (woksalizacja, oświetlenie komórek, śledzenie, aktualizacja atlasów) albo ich potoki nie powstały. Komunikat niesie błąd kompilacji, jak `S0001`. Zwykle oznacza własny hak materiału (`MaterialHooks`), który psuje `package::material::texture_source` używany przez woksalizator.

**Jak naprawić:** Sprawdź hak źródła tekstur: `sample_material_texture(slot, uv, uv_dx, uv_dy)` musi działać także w compute (z jawnymi gradientami).
