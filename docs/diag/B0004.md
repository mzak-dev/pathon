# B0004 — uchwyt tekstury jest nieaktualny albo obcy

**Co się stało:** `TextureHandle` wskazuje slot, który został zwolniony (`unregister`) albo należy do innej tablicy. Generacja uchwytu zmienia się od razu przy zwolnieniu, więc uchwyt jest martwy nawet wtedy, gdy slot zajmie już inna tekstura.

**Jak naprawić:** Nie trzymaj `TextureHandle` ani wartości shadera po `unregister`. Materiał, który używał usuniętej tekstury, trzeba zaktualizować (nowy uchwyt i `MaterialTable::set`) przed następnym `bind_group`.
