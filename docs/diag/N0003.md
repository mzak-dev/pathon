# N0003 — niepoprawne światło

**Co się stało:** `Light` łamie ograniczenia: natężenie ujemne albo nieskończone, ujemny kolor, zasięg niedodatni, albo kąty stożka reflektora poza `0 < inner <= outer <= π/2`.

**Jak naprawić:** Podaj natężenie w jednostkach fizycznych (lux dla światła kierunkowego, lumeny dla punktowego i reflektora), kolor jako liniowy odcień RGB (`1.0` = bez zabarwienia) i kąty w radianach.
