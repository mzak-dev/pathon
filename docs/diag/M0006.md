# M0006 — nieznany albo usunięty mesh

**Co się stało:** `MeshId` nie wskazuje żywego mesha tej puli: został usunięty (`remove`), pula została opróżniona (`forget_gpu`), albo uchwyt pochodzi z innej puli.

**Jak naprawić:** Nie używaj uchwytu po `remove`. Po utracie urządzenia wgraj meshe ponownie i zastąp stare uchwyty nowymi. Każda pula wystawia tylko własne uchwyty.
