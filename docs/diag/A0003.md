# A0003 — wysokość kamery poza atmosferą została przycięta

**Co się stało:** Wysokość kamery nad ziemią (z `Camera::position.y` plus `ground_offset_meters`, albo `CameraHeight::Fixed`) jest ujemna albo większa niż grubość atmosfery (domyślnie 100 km). Niebo jest liczone dla kamery wewnątrz atmosfery, więc wysokość przycięto do `1 m ..= grubość − 1 m`. Widok z kosmosu nie jest obsługiwany.

**Jak naprawić:** Ustaw `CameraHeight::FromCamera { ground_offset_meters }` tak, by `position.y + offset` była wysokością nad powierzchnią planety w metrach, albo użyj `CameraHeight::Fixed`. Dla sceny z ziemią na `y = 0` wystarczy `ground_offset_meters: 0`.
