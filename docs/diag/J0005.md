# J0005 — urządzenie nie uruchomi passów GI

**Co się stało:** Urządzenie nie ma tego, czego potrzebują passy compute GI: `Rgba16Float` jako filtrowalnej tekstury, do której compute może pisać (storage), albo grup roboczych po 64 wątki. Cecha jest wyłączona (`Negotiation::Disabled`), reszta renderera działa.

**Jak naprawić:** Użyj adaptera z obsługą storage `Rgba16Float` (wszystkie desktopowe i WebGPU core). Bez GI `PbrPack` używa środowiska.
