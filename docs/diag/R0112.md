# R0112 — zakres tekstury poza jej mipami albo warstwami

**Co się stało:** Bariera albo zadeklarowany dostęp wskazuje mip lub warstwę, których tekstura nie ma. Backend null zgłasza to zamiast po cichu przyciąć zakres.

**Jak naprawić:** Sprawdź `base_mip`, `mip_count`, `base_layer` i `layer_count` względem opisu tekstury; `u32::MAX` oznacza „do końca”.
