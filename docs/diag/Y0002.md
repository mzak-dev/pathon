# Y0002 — nieznany albo usunięty materiał

**Co się stało:** `MaterialTable::set` albo `remove` dostało `MaterialId`, którego slot jest wolny (materiał usunięty) albo nie istnieje w tej tablicy.

**Jak naprawić:** Nie używaj `MaterialId` po `remove` i nie mieszaj id z różnych tablic. Slot wraca do użytku dopiero po `frames_in_flight` klatkach (`begin_frame`), więc zachowaj uchwyty tylko dla materiałów, które nadal istnieją.
