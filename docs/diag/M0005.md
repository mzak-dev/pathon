# M0005 — mesh większy niż jeden bufor puli

**Co się stało:** Mesh ma więcej wierzchołków albo indeksów, niż mieści jeden bufor puli. Limit to najmniejsza z wartości: `max_buffer_size` i `max_storage_buffer_binding_size` urządzenia (chunk bywa bindowany jako storage w całości), `i32::MAX` wierzchołków oraz budżet puli.

**Jak naprawić:** Podziel mesh na części (np. meshlety) albo zwiększ budżet puli, jeśli to on jest limitem. Limity urządzenia są w `Caps::limits`.
