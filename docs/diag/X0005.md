# X0005 — mipmapy nie mogą być wygenerowane dla tego formatu

**Co się stało:** Źródło ma jeden poziom i prosi o generowanie mipów, ale format wybranego wariantu nie ma generatora (dziś tylko `Rgba8Unorm` i `Rgba16Float`), albo `MipmapGenerator::generate` dostał teksturę bez `SAMPLED | STORAGE`, z innym formatem albo na urządzeniu, które nie zapisuje tego formatu z compute.

**Jak naprawić:** Dostarcz cały łańcuch mip w wariancie, użyj `RGBA8` lub `RGBA16F` albo wyłącz generowanie (`TextureSource::without_mip_generation`). Wariant skompresowany z jednym poziomem nie podlega generowaniu i nie zgłasza tego błędu.
