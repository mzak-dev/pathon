# L0001 — niepoprawne ustawienia PBR

**Co się stało:** `PbrSettings` ma wartość poza zakresem: rozmiar kafla klastra to nie potęga dwójki w 4..=256, liczba warstw głębi poza 1..=64, `near` / `far` klastrów nie spełniają `0 < near < far`, `max_light_indices` jest zerem albo `environment_intensity` nie jest skończone i nieujemne. Paczka używa wtedy ustawień domyślnych.

**Jak naprawić:** Zacznij od `PbrSettings::default()` i zmieniaj pojedyncze pola w dokumentowanych zakresach.
