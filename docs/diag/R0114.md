# R0114 — niewyrównane argumenty indirect

**Co się stało:** Offset w buforze argumentów (draw, multi-draw, dispatch) albo w buforze licznika wariantów `…Count` nie jest wielokrotnością 4 bajtów. GPU czyta te dane jako `u32`, więc API graficzne odrzucają taki offset.

**Jak naprawić:** Wyrównaj offset do 4 bajtów. Elementy `DrawIndirectArgs` (16 B), `DrawIndexedIndirectArgs` (20 B) i `DispatchIndirectArgs` (12 B) są wielokrotnościami 4, więc ułożone jeden za drugim zachowują wyrównanie. Wyjście poza bufor to osobny kod, [R0108](R0108.md); brak `BufferUsage::INDIRECT` to [R0105](R0105.md); wariant `…Count` bez `Features::MULTI_DRAW_INDIRECT_COUNT` to [R0002](R0002.md).
