# S0202 — cache potoków nie został zapisany

**Co się stało:** `PersistentPipelineCache::save` pobrał blob z urządzenia, ale `CacheStore` nie zapisał go (brak uprawnień, katalog tylko do odczytu, pełny dysk). To **ostrzeżenie**: aplikacja działa dalej, a następny start kompiluje potoki od zera. Poprzedni plik zostaje nietknięty (zapis jest atomowy: plik tymczasowy i zmiana nazwy).

**Jak naprawić:** Sprawdź, czy katalog cache aplikacji istnieje i jest zapisywalny; komunikat zawiera błąd systemu.
