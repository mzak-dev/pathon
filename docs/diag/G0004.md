# G0004 — render pass miesza rozmiar renderu i wyjścia

**Co się stało:** Załączniki jednego passa mają różne klasy rozmiaru (`render_size` i `output_size`), np. przy włączonym upscalerze.

**Jak naprawić:** Użyj tej samej klasy rozmiaru dla wszystkich załączników albo przenieś pass przed / za upscaler.
