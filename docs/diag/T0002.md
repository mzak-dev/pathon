# T0002 — za dużo passów GPU w klatce

**Co się stało:** Klatka nagrała więcej GPU-passów (`BeginRenderPass`, `BeginComputePass`) niż pojemność profilera (domyślnie 128 na klatkę). Nadmiarowe passy działają normalnie, ale nie mają czasu GPU.

**Jak naprawić:** Zwiększ pojemność przez `ProfilerBuilder::with_gpu_pass_capacity`. Kosztuje 16 B na pass na slot pierścienia.
