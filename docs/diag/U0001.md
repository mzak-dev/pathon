# U0001 — slot do podglądu niedostępny w tej klatce

**Co się stało:** `SlotPreviewFeature` ma pokazać slot (np. `normals`), ale żadna paczka go w tej klatce nie zapisała. Podgląd **nie wytwarza slotów**: czyta to, co jest, a slot na żądanie (`depth_pyramid`, `roughness`, `albedo`, `reactive`) tylko zamawia w `prepare_view`, jak każdy konsument. Kafelek tego slotu jest szachownicą (magenta i szary), reszta siatki działa dalej. Diagnostyka pojawia się raz, dopóki slot nie wróci.

**Jak naprawić:** Zarejestruj paczkę, która zapisuje ten slot (kontrakt: [docs/slots.md](../slots.md)), albo usuń go z `SlotPreview::slots`. Slot na żądanie bez producenta, który go obsługuje, zostaje pusty także po zamówieniu.
