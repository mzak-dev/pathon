# U0003 — nieprawidłowe ustawienia podglądu slotów

**Co się stało:** `SlotPreview` ma wartość poza zakresem albo pustą listę slotów. Liczby są naprawiane (przycięcie albo wartość domyślna) i podgląd działa; pusta lista slotów wyłącza podgląd. Diagnostyka pojawia się raz, dopóki ustawienia są błędne.

| Pole | Zakres |
| --- | --- |
| `corner_size` | 0.05…1 |
| `depth_range` | `0 ≤ near < far`, metry |
| `motion_scale` | większe od 0 |
| `exposure` | większe od 0 |
| `slots` | co najmniej jeden slot |

**Jak naprawić:** Trzymaj `SlotPreview` w opisanych zakresach (strona [pathon-debug](../crates/pathon-debug.md)).
