# Y0001 — parametr materiału poza zakresem

**Co się stało:** `StandardMaterial::validate` (wołane przez `MaterialData::from_material` i `MaterialTable::add` / `set`) odrzuciło parametr: współczynnik albo kolor spoza `0..=1` (`metallic`, `roughness`, `clearcoat`, `transmission`, kolory podstawowe, `alpha_cutoff`…), NaN albo nieskończoność, `ior` poniżej 1, ujemny `thickness`, `emissive` albo `emissive_strength`, `attenuation_distance` niedodatni. Komunikat nazywa parametr i wartość; materiał nie trafia do tablicy.

**Jak naprawić:** Popraw wartość (zakresy ustala glTF 2.0 i rozszerzenia KHR, [docs/crates/pathon-material.md](../crates/pathon-material.md)). Przy imporcie z innego formatu przytnij wartości przed wywołaniem. `attenuation_distance: None` oznacza brak tłumienia.
