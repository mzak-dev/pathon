# S0002 — potok nie skompilował się w tle

**Co się stało:** Kompilator w tle ([ADR-0024](../adr/0024-kompilacja-w-tle.md)) nie utworzył potoku renderowania ani compute: błąd walidacji albo backendu w `create_*_pipeline` (np. layout niezgodny z shaderem, zły format celu) albo panika zadania. Draw jest pomijany albo rysowany zastępczym potokiem, zależnie od `MissPolicy` paczki; opis potoku zostaje w stanie `Failed`.

Stała potoku, która nie nazywa żadnego override shadera, ma własny kod [S0110](S0110.md).

**Jak naprawić:** Przeczytaj komunikat (etykieta potoku i błąd RHI), popraw opis potoku albo shader. `retry_failed()` ponawia po zmianie okoliczności, np. po resecie urządzenia.
