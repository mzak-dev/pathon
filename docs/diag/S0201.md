# S0201 — zapisany cache potoków nie został użyty

**Co się stało:** `PersistentPipelineCache::load` znalazł plik, ale go nie użył: jest pusty, ucięty, uszkodzony (suma kontrolna), w innej wersji formatu albo zapisany przez inną wersję pathon, albo nie dało się go odczytać. Albo `CacheSeed::adapter_mismatch` zauważył, że plik zapisał inny adapter lub sterownik niż ten, na którym działa urządzenie (backend wgpu sam odrzuca taki blob, [ADR-0019](../adr/0019-pipeline-cache-i-zrodlo-shaderow.md)). To **ostrzeżenie**: urządzenie startuje z pustym cache, a pierwszy zapis podmienia plik. Skutek to wolniejszy pierwszy start (potoki kompilują się od zera), nic więcej.

**Jak naprawić:** Zwykle nic: po jednym uruchomieniu plik jest zapisany na nowo. Gdy ostrzeżenie wraca przy każdym starcie, host zapisuje cache pod jedną ścieżką dla kilku adapterów (podaj osobną ścieżkę na adapter) albo nie wywołuje `save` przy zamknięciu.
