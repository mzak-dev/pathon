# K0007 — obserwator plików niedostępny albo zgubił zdarzenia

**Co się stało:** System nie dał powiadomień o plikach (brak limitów inotify, katalog sieciowy, usunięty obserwowany katalog) albo obserwator zgłosił błąd. `pathon-hot` przechodzi wtedy na odpytywanie katalogów (domyślnie co 250 ms), a po każdym takim zdarzeniu czyta katalogi od nowa, więc zmiana nie ginie. To **ostrzeżenie**.

**Jak naprawić:** Zwykle nic. Przy powtarzaniu sprawdź limity systemu (`fs.inotify.max_user_watches`) albo obserwuj katalog lokalny.
