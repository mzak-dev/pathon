# S0107 — nieznana nazwa w shaderze

**Co się stało:** Shader używa identyfikatora, typu, funkcji, atrybutu albo rozszerzenia (`enable`), którego naga nie zna: literówka, brak `import` albo brak deklaracji. Błąd wskazuje to miejsce w oryginalnym pliku (nazwy z prefiksem ścieżki modułu, jak `package_colors_pack`, są pokazane jako `colors::pack`). Podpowiedź: najbliższa nazwa występująca w złożonym shaderze (`czy chodziło o …`).

**Jak naprawić:** Popraw nazwę, dopisz `import package::moduł::nazwa;` albo zadeklaruj brakujący element. Wesl nie sprawdza nazw: błąd wychodzi dopiero z naga ([ADR-0021](../adr/0021-importy-shaderow-wesl.md)), więc import elementu, którego nikt nie używa, nie jest zgłaszany.
