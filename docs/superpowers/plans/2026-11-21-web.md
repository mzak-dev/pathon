# Web — plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cel:** przykład `clear` działa w przeglądarce z WebGPU, a bez WebGPU pokazuje komunikat; CI raportuje rozmiar WASM.

**Architektura:** `pathon-platform-winit` z backendem webowym winita (`spawn_app`, canvas); runner fasady `pathon` bez wątków na wasm (`build_async`, `requestAnimationFrame`); przykład w osobnym crate `examples/web`.

**Stack:** Rust 2024, winit 0.30 (web), wgpu 30 (`webgpu`), `wasm-bindgen`, `wasm-bindgen-futures`, `web-sys`, `wasm-pack`.

**Spec:** [ADR-0014](../../adr/0014-web-przez-winit-i-runner-bez-watkow.md), M0-03 i M0-06 w [planie implementacji](../../plan-implementacji.md).

## Ograniczenia globalne

- Zależności webowe tylko pod `[target.'cfg(target_arch = "wasm32")'.dependencies]`; natywny graf zależności `pathon-core` bez zmian (deps-check, baseline 126).
- Natywne zachowanie runnera i platformy bez zmian (istniejące testy, przykłady).
- Kod samokomentujący; tekst w stronie i docs po polsku (komunikat bez WebGPU także po angielsku).

## Review Focus

1. Brak WebGPU (brak `navigator.gpu` albo adaptera) → komunikat w stronie, bez paniki w konsoli — sprawdzane w przeglądarce w aplikacji (ma `navigator.gpu`, ale nie daje adaptera) — Task 2.
2. Zmiana rozmiaru okna przeglądarki zmienia rozmiar canvasu i celu (bez rozciągania obrazu) — Task 1.
3. Klatki przed zakończeniem `build_async` są pomijane, nie panikują — Task 1.

### Task 1: Web w `pathon-platform-winit` i runner bez wątków

**Files:** `crates/pathon-platform-winit/` (Cargo.toml, src), `crates/pathon/` (Cargo.toml, `src/lib.rs`, `src/runtime.rs` — część wasm w osobnym module, np. `src/runtime/web.rs`), root `Cargo.toml` (workspace deps), `docs/crates/pathon-platform-winit.md`, `docs/crates/pathon.md`.

**Interfaces:**
- `pathon::runtime::run` i `run_with_hook` — te same sygnatury na wasm (bez `Send` w bound hooka tam, gdzie wasm tego nie wymaga — użyj `MaybeSend`).
- `pathon-platform-winit`: `WinitPlatform::new()` na wasm; `Platform::run` przez `EventLoopExtWebSys::spawn_app`; canvas w elemencie `#pathon` albo `<body>`.

- [ ] **Step 1:** `cargo check --target wasm32-unknown-unknown -p pathon --features runtime,winit` (albo domyślne features) — dziś się nie kompiluje albo nie ma runnera na wasm; zapisz wynik.
- [ ] **Step 2: Implementacja** według ADR-0014; komunikat bez WebGPU: element `<p id="pathon-no-webgpu">` z tekstem PL/EN zamiast canvasu.
- [ ] **Step 3: Uruchom** natywnie `cargo test --workspace --all-features`, clippy `-D warnings`, `cargo check --target wasm32-unknown-unknown -p pathon` (z features platformy) i istniejący check wasm z CI.
- [ ] **Step 4: Commit** `feat(platform): run pathon in the browser through winit and a thread-free runner (ADR-0014)`
