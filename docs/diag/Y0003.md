# Y0003 — hook shadera materiału się nie kompiluje

**Co się stało:** `MaterialHooks::validate` złożyło moduły materiału z podmienionym hookiem (`material::hooks` albo `material::texture_source`) i nie przeszły składania wesl albo walidacji naga, bez żadnej flagi albo ze wszystkimi naraz. Komunikat zawiera błąd shadera z pozycją w złożonym tekście.

**Jak naprawić:** Zachowaj sygnaturę domyślnego modułu: `fn modify_surface(input: SurfaceInput, surface: Surface) -> Surface` albo `fn sample_material_texture(slot: u32, uv: vec2<f32>, uv_dx: vec2<f32>, uv_dy: vec2<f32>) -> vec4<f32>`. Importuj typy z `package::material::surface`. Hook nie może zależeć od flagi, której nie ma w każdej permutacji ([docs/crates/pathon-material.md](../crates/pathon-material.md)).
