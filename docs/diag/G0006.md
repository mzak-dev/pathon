# G0006 — kolejność passów rozstrzygnięta kolejnością rejestracji

**Co się stało:** Dwa passy na tym samym etapie i z tym samym priorytetem nie mają między sobą zależności, więc o kolejności zdecydowała rejestracja.

**Jak naprawić:** Dodaj `before` / `after` albo różne priorytety, jeśli kolejność ma znaczenie.
