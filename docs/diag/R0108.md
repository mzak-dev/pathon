# R0108 — dostęp do bufora poza zakresem

**Co się stało:** Zapis albo kopia wychodzi poza rozmiar bufora. Dotyczy też komend indirect: `offset + liczba_elementów * rozmiar_elementu` (dla wariantów `…Count` liczba to `max_count`, a licznik zajmuje 4 B) przekracza rozmiar bufora argumentów.

**Jak naprawić:** Sprawdź offset i rozmiar. Dla multi-draw bufor musi pomieścić `count` (albo `max_count`) elementów, nawet jeśli GPU narysuje mniej.
