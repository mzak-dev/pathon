# Q0003 — tonemapping pominięty, brak slotu `exposure`

**Co się stało:** Pass tonemappingu znalazł slot `hdr`, ale nikt nie zapisał w tej klatce slotu `exposure` (kontrakt w [docs/slots.md](../slots.md)). Bez mnożnika paczka nie zgaduje jasności: pomija pass, więc `output` zostaje takie, jakie było.

**Jak naprawić:** Zarejestruj `PostPack` (zawiera `ExposureFeature`) albo zapisz `Slot::EXPOSURE` (`R32Float` 1×1) z własnej paczki przed etapem `Tonemap`. Gdy `ExposureFeature` został wyłączony przy negocjacji (F0101), urządzenie nie pisze `R32Float` z compute.
