# N0004 — wartość sceny nie jest skończona

**Co się stało:** Transformacja instancji, kamery albo światła zawiera `NaN` lub nieskończoność. Scena odrzuca ją przy zapisie, więc poprzednia wartość zostaje, a `NaN` nie dociera do macierzy ani do GPU.

**Jak naprawić:** Sprawdź dane hosta (skala zero w odwracanej macierzy, dzielenie przez zero w animacji) zanim wywołasz `extract`.
