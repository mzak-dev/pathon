# S0105 — niepoprawne `@if`, `@elif` albo `@else`

**Co się stało:** Translacja warunkowa WESL odrzuciła atrybut: kilka `@if` / `@elif` / `@else` na jednym węźle, `@elif` bez poprzedzającego `@if`, wyrażenie, które nie składa się z nazw flag, `!`, `&&`, `||` i nawiasów. Błąd wskazuje deklarację albo instrukcję z atrybutem.

**Jak naprawić:** Połącz warunki w jednym atrybucie (`@if(a && b)`) albo użyj łańcucha `@if` / `@elif` / `@else` na kolejnych węzłach. Flagi włącza się w `ShaderFeatures`; flaga, której nikt nie włączył, jest wyłączona (literówkę w nazwie flagi wykrywa ostrzeżenie [S0106](S0106.md) od strony hosta).
