# R0104 — nieprawidłowa lista komend

**Co się stało:** Komenda nagrana w złym rodzaju passa, draw bez pipeline'u, niezamknięty pass albo grupa debug. Dotyczy też `set_immediates` (ADR-0018) poza passem, bez ustawionego potoku, z `offset` lub długością niewyrównaną do 4 B albo sięgającą poza `immediate_size` potoku.

**Jak naprawić:** Nagrywaj przez enkodery `render_pass()` / `compute_pass()`, które same zamykają pass. Przy immediates ustaw potok przed `set_immediates`, zapisz cały blok `0..immediate_size` przed każdym draw/dispatch i zapisz go od nowa po każdym `set_pipeline`; `set_immediates` bez `Features::IMMEDIATES` odrzuca backend wgpu.
