# F0102 — dwie paczki zajmują tę samą rolę

**Co się stało:** Dwie zarejestrowane paczki deklarują tę samą rolę (np. TemporalResolve). Aktywna jest pierwsza w kolejności klatki, której `setup` się udał; jeśli pierwsza padnie w `setup` (F0104), rolę przejmuje następna.

**Jak naprawić:** Wyrejestruj jedną z paczek.
