# F0105 — paczka zawiodła przy nagrywaniu klatki

**Co się stało:** `record()` paczki albo nagranie jednego z jej passów zwróciło błąd. Paczka została wyłączona, a klatka narysowana bez niej.

**Jak naprawić:** Popraw błąd z komunikatu (zwykle niepoprawny handle albo bind group). Po utracie urządzenia `recover()` / `reset()` przywraca paczkę ([ADR-0013](../adr/0013-dwa-widoki-na-celu-i-paczki-po-resecie.md)); jeśli błąd się powtórzy, paczka znów zostanie wyłączona z F0105.
