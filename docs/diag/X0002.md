# X0002 — niepoprawne źródło tekstury

**Co się stało:** `TextureSource::validate` odrzuciło źródło: rozmiar albo liczba warstw równa zero, brak wariantów, format spoza kolorowych, więcej poziomów mip niż mieści tekstura, rozmiar skompresowanego wariantu niepodzielny przez rozmiar bloku (4×4) albo długość poziomu inna niż `bloki × rozmiar bloku × warstwy`. Komunikat wskazuje format i poziom.

**Jak naprawić:** Poziom *N* ma wymiary `max(1, rozmiar >> N)`; skompresowany poziom liczy bloki 4×4 w górę (mip 1×1 zajmuje jeden blok), a wszystkie warstwy idą po kolei w jednym poziomie. Rozmiar bazowy skompresowanej tekstury musi być wielokrotnością 4.
