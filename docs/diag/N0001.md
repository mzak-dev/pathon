# N0001 — nieaktualny uchwyt sceny

**Co się stało:** Host użył `InstanceId`, `CameraId` albo `LightId` obiektu, który został już usunięty (`despawn`), albo uchwytu z innej sceny. Slot po usuniętym obiekcie jest używany ponownie, ale z nową generacją, więc stary uchwyt nigdy nie trafia w nowy obiekt.

**Jak naprawić:** Po `despawn` przestań używać uchwytu; po ponownym `spawn` zapamiętaj nowy. Jeśli adapter hosta mapuje własne encje na uchwyty sceny, usuwaj wpis z mapy razem z `despawn`.
