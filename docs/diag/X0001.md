# X0001 — brak wariantu tekstury, który to urządzenie próbkuje

**Co się stało:** Żaden z wariantów `TextureSource` nie jest użyteczny na tym GPU: skompresowane formaty (BC, ASTC, ETC2) nie są włączone w `Caps`, a nieskompresowane albo nie mają `SAMPLED | FILTERABLE`, albo nie istnieją w przestrzeni kolorów źródła (np. ETC2 dla `ColorSpace::Srgb`, `Rgba16Float` jako sRGB). Komunikat podaje formaty, które źródło oferowało.

**Jak naprawić:** Dodaj do źródła wariant nieskompresowany (`Variant::rgba8`) obok skompresowanych; pathon nie przekodowuje BCn na CPU. Dla iOS i Androida dołóż wariant ASTC albo ETC2. Format `Rgba32Float` nie jest filtrowalny bez `FLOAT32_FILTERABLE`: użyj `Rgba16Float`.
