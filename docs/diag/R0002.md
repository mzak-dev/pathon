# R0002 — adapter nie ma wymaganych funkcji

**Co się stało:** `DeviceRequest::required_features` zawiera bity, których adapter nie obsługuje. Zgłaszany też przy tworzeniu potoku z `immediate_size > 0` bez `Features::IMMEDIATES`.

**Jak naprawić:** Przenieś funkcję do `optional_features` i obsłuż jej brak w `negotiate()` paczki albo wybierz inny adapter.
