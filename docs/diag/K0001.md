# K0001 — plik shadera poza obserwowanym katalogiem

**Co się stało:** `pathon-hot` pominął plik, który nie leży pod żadnym obserwowanym katalogiem po rozwiązaniu dowiązań: dowiązanie symboliczne (albo junction w Windows) wskazuje poza katalog, albo jest dowiązaniem do katalogu. Dowiązań do katalogów nie śledzimy nigdy, dowiązanie do pliku liczy się tylko wtedy, gdy jego cel leży w tym samym katalogu. To **ostrzeżenie**: reszta plików działa, a plik nie trafia do biblioteki shaderów ([ADR-0040](../adr/0040-hot-reload-shaderow.md)).

**Jak naprawić:** Umieść plik (albo kopię) wewnątrz obserwowanego katalogu, albo dodaj katalog docelowy do `HotConfig` osobno.
