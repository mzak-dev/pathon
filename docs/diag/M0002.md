# M0002 — dane mesha nie pasują do layoutu puli

**Co się stało:** `GeometryPool::upload` odrzucił `MeshData`. Możliwe przyczyny: liczba strumieni różni się od liczby strumieni layoutu puli; długość strumienia nie jest wielokrotnością jego `stride`; strumienie mają różną liczbę wierzchołków; mesh nie ma wierzchołków ani indeksów; któryś indeks wskazuje wierzchołek poza zakresem.

**Jak naprawić:** Zbuduj dane tym samym layoutem, którym utworzono pulę. Każdy strumień ma `vertex_count * stride` bajtów, a indeksy są mniejsze niż `vertex_count`.
