# I0003 — to urządzenie nie zbuduje oświetlenia IBL

**Co się stało:** Mapy powstają w compute i są zapisywane do `Rgba16Float`. Urządzenie nie daje temu formatowi `SAMPLED | FILTERABLE | STORAGE` albo ma za małe limity (grupy 8×8 = 64 wątki, sześć warstw tekstury). Paczka `IblPack` w takim przypadku jest wyłączona już w negocjacji (`F0101`).

**Jak naprawić:** Użyj urządzenia, które zapisuje `Rgba16Float` z compute (każde z WebGPU i natywnych profili Desktop). Dla Web nie ma obejścia: `rgba16float` jako storage jest w rdzeniu WebGPU. Gdy trzeba działać bez compute, dostarcz gotowe mapy zbudowane offline (poza zakresem M4-06).
