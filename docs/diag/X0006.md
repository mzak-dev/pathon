# X0006 — tekstura użyła formatu zastępczego

**Co się stało:** Źródło oferowało bardziej zwarte kodowanie (BC, ASTC, ETC2) niż to, które wybrano, ale to GPU go nie próbkuje, więc loader wgrał wariant mniej zwarty (zwykle nieskompresowany RGBA8). Obraz jest poprawny, kosztuje więcej pamięci i przepustowości.

**Jak naprawić:** Nic, jeśli to oczekiwane (np. Apple GPU bez BCn). Chcąc zmniejszyć zużycie pamięci tam, dołóż wariant ASTC albo ETC2 do źródła.
