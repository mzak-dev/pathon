# S0104 — deklaracje zależą od siebie cyklicznie

**Co się stało:** Funkcja (albo inna deklaracja) wywołuje samą siebie bezpośrednio lub przez inne moduły (`a::f` → `b::g` → `a::f`). WGSL nie dopuszcza rekurencji. Cykl między *importami* modułów jest dozwolony, dopóki deklaracje nie wołają się nawzajem; błąd wskazuje deklarację, od której wesl zaczął wykrywać cykl, w jej własnym pliku.

**Jak naprawić:** Wyciągnij to, czego potrzebują obie deklaracje, do trzeciego modułu albo zamień rekurencję na pętlę.
