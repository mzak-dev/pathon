# S0103 — import nazwy, której moduł nie deklaruje

**Co się stało:** Moduł istnieje, ale nie ma funkcji, struktury, stałej ani innego elementu o importowanej nazwie (albo element ma widoczność niedostępną dla importującego). Błąd wskazuje nazwę w linii `import`. Podpowiedź: podobna nazwa zadeklarowana w module (`czy chodziło o …`) albo lista tego, co moduł deklaruje.

**Jak naprawić:** Popraw nazwę w `import` albo dodaj deklarację do modułu.
