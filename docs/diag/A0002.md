# A0002 — niebo nie zamieniło się w obraz środowiska

**Co się stało:** `SkyEnvironmentFeature` zbudowała na CPU obraz equirect z nieba, ale `EquirectImage` go odrzucił (zły rozmiar albo wartość nieskończona). Poprzednie `IblSource` w `Shared` zostaje; ta sama konfiguracja nie jest ponawiana co klatkę.

**Jak naprawić:** To błąd paczki, nie ustawień: ustawienia są sprawdzane i naprawiane wcześniej (A0001). Zgłoś go z wartościami `SkySettings` z tej klatki. Jako obejście wyłącz `SkyIblSettings::enabled` i dostarcz własny `IblSource`.
